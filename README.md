# Convox  

**Convox** is a chat application for Android built using Java and XML. The app is still under development, with basic functionalities like user login and registration implemented.

## Features  
- **User Registration**: Allows new users to sign up.  
- **Login**: Secure login for registered users.  

## Tech Stack  
- **Language**: Java  
- **UI**: XML  
- **Development Environment**: Android Studio  

## Current Status  
The app is a work in progress. Only login and registration features are available so far. More features like chat functionality, user profiles, and real-time messaging will be added in future updates.
